# CodexMeter 消耗指标图改版设计

## 目标

重做 CodexMeter 浮层中的四个指标模块，使用户能快速回答：

- 本周额度还剩多少。
- 今日消耗相较昨日同一时间是上升还是下降。
- 本周逐日消耗相较上周同期是上升还是下降。
- 本机历史 Token 主要由普通输入、缓存输入和输出中的哪一类构成。

本次只调整浮层的消耗指标展示，不修改额度来源、状态栏红绿灯规则、刷新策略、右键菜单或日志扫描方式。

## 整体布局

- 浮层宽度保持 `320 pt`。
- 标题栏与额度卡交互保持不变。
- 今日、本周卡片增高，以容纳对比图和横轴。
- 本机总量卡片增高，以容纳构成环和三行明细。
- 浮层总高度由约 `382 pt` 调整为约 `444 pt`。
- 不增加动画、悬停详情或可点击图表，保持低资源占用。

## 四个模块标题

“本周剩余”“今日消耗”“本周消耗”“本机总量”使用统一视觉层级：

- 字号 `9 pt`，中等字重。
- 使用弱化的次级文字颜色，不与核心数值竞争。
- 标题前放置 `3 x 9 pt` 的圆角短竖线。
- 短竖线颜色跟随模块主色：
  - 本周剩余、本周消耗：蓝色。
  - 今日消耗：绿色。
  - 本机总量：紫色。
- 四个标题使用一致的顶部、左侧内边距和基线位置。

## 今日消耗

### 信息

- 左侧显示今日累计 Token。
- 右上角显示与昨日同一时间范围相比的变化。
- 图表横轴为 `00 时` 到 `现在`。

### 图形

- 今日每小时消耗使用绿色实线。
- 实线下方使用低透明绿色渐变面积。
- 昨日同一小时范围使用低透明虚线。
- 今日曲线末端显示小圆点，明确当前时间位置。
- 只绘制从零点到当前小时的数据，不把未来小时的零值画入图表。

### 对比文案

- 今日高于昨日：`↑ N% 较昨日`。
- 今日低于昨日：`↓ N% 较昨日`。
- 两者相等：`与昨日持平`。
- 昨日为零且今日大于零：`今日新增`。
- 两者均为零：`暂无消耗`。

## 本周消耗

### 信息

- 左侧显示本周从周一至今累计 Token。
- 右上角显示与上周相同星期范围相比的变化。
- 横轴为 `周一` 到 `今天`。

### 图形

- 每天使用一组两根柱：
  - 灰色弱化柱表示上周对应日期。
  - 蓝色主柱表示本周对应日期。
- 只展示周一至今天，不展示本周未来日期。
- 柱图区域与横轴标签之间保留至少 `8 pt` 的垂直间距，避免柱形压到“周一 / 今天”。

### 对比文案

沿用今日消耗的百分比、持平、新增和暂无消耗规则，将“昨日”替换为“上周”。

## 本机总量

### 信息层级

- 左上角显示“本机总量”弱化标题。
- 右上角显示等效 credits。
- 构成环中心显示历史总 Token。
- 右侧依次展示：
  - 普通输入：绝对值和占比。
  - 缓存输入：绝对值和占比。
  - 输出：绝对值和占比。

### 构成环

- 普通输入使用莫兰迪粉色。
- 缓存输入使用莫兰迪紫色。
- 输出使用莫兰迪黄色。
- 圆环不使用动画、阴影扩散或渐变旋转。
- 占比以 `allTimeUsage.totalTokens` 为分母。
- 无法归类的 Token 计入普通输入，保持与现有分项文案口径一致。
- 总量为零时显示中性灰色空环，三项占比均显示 `0%`。

### 移除内容

- 移除本机总量月折线。
- 移除起始月份与“本月”横轴。
- 移除底部以点号连接的单行构成文案。

## 数据模型

在现有不可变 `UsageSnapshot` 中新增：

- 昨日从零点到当前小时的每小时消耗数组。
- 上周从周一到当前星期的每日消耗数组。
- 今日与昨日同期总量。
- 本周与上周同期总量。

数据直接由现有 `UsageBuckets.hourly` 和 `UsageBuckets.daily` 聚合，不增加日志扫描次数，不复制会话原文，不新增持久化文件。现有索引已经保留历史小时和日桶，因此无需重扫日志格式或迁移索引。

## 组件边界

- `UsageBuckets`：生成当前与上一周期的对比数组和总量。
- `UsageComparison`：把当前值、上一周期值转换为对比状态和百分比。
- `ComparisonTrendView`：绘制今日实线、昨日虚线和面积。
- `GroupedBarChartView`：绘制本周与上周同期分组柱。
- `TokenCompositionRingView`：绘制历史 Token 构成环。
- `UsagePopoverController`：负责卡片布局和文案绑定，不执行统计计算。

三个图表组件均使用 `NSView` 和 `NSBezierPath` 静态绘制，不引入图表依赖。

## 性能

- 图表仅在 `UsageSnapshot` 变化时重绘。
- 对比数组最多包含 24 个小时点和 7 个日点。
- 不使用 `Timer` 驱动动画。
- 不增加目录监听、磁盘扫描或网络请求。

## 测试

核心测试覆盖：

- 昨日同一时间范围的小时桶切片。
- 上周同一星期范围的日桶切片。
- 跨天、跨周和时区边界。
- 百分比上升、下降、持平、上一周期为零、双方为零。
- 普通输入、缓存输入、输出及未分类 Token 的占比。
- 总量为零时的构成结果。
- 图表几何点和柱形不会超出绘制边界。

## 验收标准

- 四个模块标题字号、颜色、锚点和位置一致。
- 今日图能区分今日与昨日同期。
- 本周图能区分本周与上周同期，柱形不压住横轴文字。
- 本机总量只展示构成环，不再显示折线。
- 无额度数据和无 Token 数据时布局不跳动。
- 浮层打开、关闭和刷新行为保持不变。
- 核心测试、release 构建和本地 App 启动检查通过。
