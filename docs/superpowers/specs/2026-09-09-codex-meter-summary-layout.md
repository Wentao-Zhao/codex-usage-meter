# 本机总量布局调整

采用已确认的 C 融合版，将总量从圆环内移出，避免较长数字拥挤。

- 总量、今日消耗、本周消耗使用相同的数值字号与字重，卡片沿用统一背景和边框。
- 上方左侧显示总量与弱化的 Tokens 单位，右侧显示静态分段比例条。
- 下方保留普通输入、缓存输入、输出三列，各列第一行左侧为名称、右侧为百分比，第二行为数值。
- 百分比最多显示一位小数；非零且不足 1% 时显示 `<1%`，零值显示 `0%`。
- 悬停总量和分项数值显示完整 Token 数。
- 面板宽度保持 320 pt，本机总量卡片高度为 110 pt；普通和长数字使用同一布局。
- 分段比例保持真实占比，不为小分段虚增宽度；总量为零时显示中性背景条。

本次仅调整展示，不改动额度来源、Token 统计、刷新频率或菜单栏交互，不增加定时器和动画。

验证覆盖原生深浅色截图、普通及长数字、零数据、无五小时额度、单一构成占满比例条，并运行现有逻辑检查和发布构建。
